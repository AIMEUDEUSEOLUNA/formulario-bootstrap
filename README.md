# Formulário Bootstrap

## Objetivo

Criar um formulário de inscrição para uma Mostra de Tecnologia e Inovação do lunao utilizando HTML, CSS, Bootstrap e GitHub Pages.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- GitHub Pages

## Tipos de input utilizados

O formulário utiliza os seguintes tipos de input:

- text
- email
- password
- number
- tel
- url
- search
- date
- month
- week
- time
- datetime-local
- color
- range
- file
- checkbox
- radio
- hidden
- submit
- reset
- button
- image

Também foram utilizados:

- select
- textarea
- datalist
- fieldset
- legend

- required
- min
- max

- maxlength
- accept
- step

## Investigação

### O que é um formulário HTML?

Um formulário HTML permite coletar informações fornecidas pelo usuário por meio de campos como textos, números, opções e arquivos.

### O que é o Bootstrap?

Bootstrap é um framework CSS que fornece classes prontas para estilização, organização e criação de páginas responsivas.

### O que é o atributo required?

O atributo required determina que o campo precisa ser preenchido antes do envio do formulário.

### O que é o atributo pattern?

O atributo pattern permite definir um padrão que o valor digitado deve seguir.

### O que é o select?

O elemento select cria uma lista de opções para o usuário escolher.

### O que é o textarea?

O elemento textarea cria uma área destinada à entrada de textos maiores.
